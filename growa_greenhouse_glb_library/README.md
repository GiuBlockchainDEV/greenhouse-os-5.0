# Growa Greenhouse GLB Component Library

- Format: glTF 2.0 binary (.glb)
- Units: meters
- Up axis: Y
- Draco: disabled
- Materials: embedded PBR Metallic-Roughness with base-color, metallic-roughness, normal and occlusion textures
- Geometry: modular, low-poly, intended for React Three Fiber instancing/repetition
- Origins: attachment-centric; see manifest.json

These are dimensionally coherent reference models based on realistic greenhouse component proportions.
Where manufacturer/shop dimensions are required, replace the reference dimensions while preserving origin and axis conventions.
